# 镜序｜本地原创短剧工作台

镜序是一个本地运行的短剧制作桌。可以手工建立作品、分集和镜头，导入有来源记录的素材，明确选片并设置剪辑切点，编辑字幕，使用 FFmpeg 导出 MP4／SRT／机器核验报告，并制作包含作品数据与素材二进制的完整 ZIP 备份。队列只有在操作者显式启动本地处理后才领取任务。

界面与代码由本项目独立实现。示例“雨夜来客”是虚构演示，静帧不是生成视频。第三方工具、模型、字体及用户导入素材各自有独立许可；本项目不承诺所有 AI 输出自动具备版权或可商用。参见 [来源与依赖](docs/ORIGIN.md)。

## 启动

需要 Python 3.12+、可在命令行找到的 `ffmpeg` 与 `ffprobe`。前端使用浏览器原生模块，不需要 npm 构建；自动测试需要 Node.js 20+。在仓库根目录执行：

```powershell
python -m workbench.server --data-root .workbench-data --port 8766
```

打开终端打印的 `http://127.0.0.1:8766/`。默认只监听本机。数据目录由 `--data-root` 指定；上述相对路径留在仓库内但被 Git 忽略。实际作品和备份请保存在操作者自己选择的位置，并自行管理备份副本。Windows 本机若 `python` 命令未配置，可用已安装的 Python 3.12 可执行文件替换它；不需要复制运行目录进源码仓库。

## 从空白作品到成片

1. 新建作品与分集，在“编导／分镜”写剧本、场景、镜头任务和原生对白。“编导”可填写下一集期待及每场的时间，保存到分集创作备注并随备份恢复；故事提示只检查明示记录，不评判创作质量。并发修改若让场景已保存但时间备注未保存，界面会明确提示刷新后重试。保存后重新载入可继续编辑；也可明确创建虚构演示作品。
2. 在“素材”导入自己有权使用的图片、视频或声音，填写来源与授权说明。导入不会自动选片，也不等于人工审看通过。
3. 在“分镜”选择实际视频候选；到“导出”读取媒体时长、设置片段入点与出点并保存时间轴。
4. 在“校核”逐条编辑字幕时间、文本、说话人与源视频；需要时下载 SRT。对白或镜头版本变化后，已保存字幕会标为待重新对齐。SRT 保留文字中的 `&`、引号与 Unicode；标记或控制字符会明确拒绝。可手工记录实录并查看文本差异线索；配置了本地离线 ASR 后，还可选择当前镜头已选视频的音轨。机器文本只供核对，真实对白仍需人工听审。
5. 在“导出”排队生成 MP4，转到“任务”显式启动本地处理。排队后的镜头、选片、素材、时间轴、字幕或人工校核变化会要求重新排队。完成后下载 MP4、SRT（若选择包含字幕）和 JSON 报告。导出会重新编码、检查音视频可解码及基本技术属性；报告的 `human_reviewed: false` 表示还没有人工验收。状态未知的 CPU 文本任务可在任务详情中由操作者填写说明并确认仅结束本地等待；这不是外部结束或成功的核验，也不会取消外部请求或自动重投。
6. 在“导出”生成完整 ZIP 备份并下载。核心作品记录与时间轴、字幕、人工校核取自同一个数据库快照；恢复会先在隔离目录验证二进制和当前选片的实际媒体、音轨及切点，再导入作品。若同 ID 作品已存在，会拒绝并保留原数据。

“设置”显示视频、文本与离线 ASR 的当前配置状态。未配置时手工工作和已有视频的本地导出仍可用；不会伪造模型生成结果。可选模型只通过数据目录中被忽略的 `operator-config.json` 指向操作者已有的服务或离线模型；请自行核对兼容性与许可，不把配置、密钥或权重提交到 Git。Codex 当前会话或订阅不是模型 API 凭据。未经单独配置与真实运行，不应把协议测试称作 H3 生成或 ASR 验证。

## 测试与发布

```powershell
python -m unittest discover -s tests -v
node --test tests/frontend.test.mjs
python tools/check_public_files.py
```

发布校验器读取 Git 索引中已跟踪／暂存的实际对象字节；命令行明确列出的未跟踪候选文件才读取工作区，例如 `python tools/check_public_files.py path/to/new-file.py`。已跟踪文件即使列为候选，仍以索引为准。它拒绝数据库、运行配置、密钥、日志、模型权重和真实媒体；仅三张有来源与固定哈希的虚构设计 PNG 例外。它不会读取整个被忽略的运行目录，也不能代替发布前人工检查暂存清单和内容。完整验证范围与限制见 [验证说明](docs/VERIFICATION.md)。

目前仅准备私有仓库发布；本仓库没有给第三方代码、模型或素材授予公开许可。上传、远端 commit 与可见性须分别核验。
