## 本地复现

在仓库根目录运行：

```powershell
python -m unittest discover -s tests -v
node --test tests/frontend.test.mjs
python tools/check_public_files.py
ffmpeg -version
ffprobe -version
```

Python 集成测试会调用本机 FFmpeg 构造和探测合成媒体。独立核验还应以合成视频、音轨与 Unicode SRT 导出 MP4，再用 ffprobe 查看音视频流并完整解码，核对导出报告哈希和 `human_reviewed: false`。FFmpeg 命令通过只说明技术格式、解码与字幕管线有效，不说明画面内容或真实对白达到成片标准。不同机器的编码器和字幕滤镜可能不同，须在目标机实测。

发布检查直接读取 Git 索引中的 blob 与文件模式；显式给出的未跟踪候选才读取工作区。已跟踪路径即便再次指定为候选，也以索引内容为准；未暂存的修改不属于本次发布集合。检查不会扫描被忽略的运行目录。它拒绝常见数据库、密钥、个人配置、日志、真实视频／音频、模型权重与未列白名单图片，并检查文本中的高置信凭据和个人绝对路径。提交或上传前仍须人工核查 `git diff --cached --name-only`、`git diff --cached` 与目标仓库的可见性；自动规则无法识别全部隐私或许可问题。

## 当前限制

- ComfyUI／文本／ASR 适配器的测试使用虚构响应或本地协议样本；未调用真实 H3、真实文本服务或下载／运行 ASR 权重。未配置时界面显示未配置，不能称为生成成功。
- 当前选片视频音轨可作为离线 ASR 来源；自动测试仅用合成视频与假 ASR 运行时验证来源、哈希和镜头版本围栏，未证明实际语音识别质量。未知文本请求的本地人工收束只记录操作者确认和说明，不证明外部服务停止、失败或成功。
- 静帧仅为虚构演示资产。技术导出的声音是合成音调，不是对白；没有人工听审、演员表演、剧情连续性、艺术质量或整集验收结论。
- 备份测试核对并发写入下核心记录与后期记录同一 SQLite 快照，以及恢复前的哈希、真实视频时长、音轨、对白切点和完整解码；不合格恢复不会写入目标作品或素材。用户仍应将下载的 ZIP 另存并定期试恢复。
- 本地测试、浏览器操作与 GitHub 上传是不同证据。只有创建私有仓库、推送并核验远端 commit 后才能称为已上传；本文件不作该声明。
