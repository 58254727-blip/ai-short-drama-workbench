# 镜序｜界面设计约束

参考：`workbench-concept-v1.png`，原创 Image Gen 概念，完整主屏1536×1024。实现为代码原生HTML/CSS/ES Modules，不把截图切片当界面；界面颜色与排布以概念为准。

## 配色与文字

- 主底色 #12171b，表面 #1a2227，分隔线 #334047；主文字 #eef2f2，次文字 #9eaaae。
- 青绿 #48bca6 用于主要动作和选中标记；待审琥珀 #d9a55e；错误为清楚的红色，不能只用颜色区分状态。
- 中文系统字体：Microsoft YaHei UI、PingFang SC、system-ui、sans-serif。主标题26–30px、导航14–16px、正文14px、辅助12px；字段标签和控件大小明确设置，不用浏览器默认字样。
- 6px主圆角、1px分隔线、朴素轮廓图标、可见焦点。减少动效，尊重prefers-reduced-motion。

## 信息架构与允许的主屏文字

顶部：镜序、作品选择、分集选择、设置。
左导航：编导、分镜、素材、任务、校核、导出。
分镜主屏：分镜工作台；把每一个镜头，接成一场戏。；新增镜头。
编辑区：镜头列表、示例画面、镜头任务、起始状态、主要动作、结束状态、转场与声音。
右侧：镜头、资产、画面时长、生成时长、原生对白、参考素材、保存修改、加入队列。
底部：选片与时间轴、本地工作台、尚未提交生成任务。

示例作品“雨夜来客”及雨巷镜头只供演示，必须与用户实际项目分开，不能虚构生成成功、人工审看或验收记录。第一屏不出现外部人物或旧短剧。

## 布局与组件

- 54px左右顶部栏；约128px导航；内容左约280px镜头列表，中间灵活预览/编辑，右约360px检查器；底部统一时间轴。
- 主屏是制作桌，不是营销页或卡片网格。用工作区、列表、表单、预览、抽屉和底部时间轴；避免反复嵌套圆角卡片。
- 导航、下拉、字段、可编辑镜头列表、预览、时间轴、队列表、字幕表各为独立模块。app.js只组合状态与模块，不做巨大单文件。
- 1280px以下收窄列表/检查器；窄屏按导航、列表、预览、表单次序纵排或抽屉化，不能裁掉主要按钮。

## 功能必要的明确偏差

- 概念底部自动画出的D盘示例路径不硬编码；显示真实配置的项目位置或不显示路径。
- 没有真实视频时，示例图不冒充视频；播放控件禁用并说明原因。没有选片时的镜头长度是剪辑预算，不能标为已完成媒体。
- 动态项目名、集名、镜头文案和状态来自真实API，只有明确创建的虚构演示项目才能呈现示例内容。
- 同一套视觉系统延伸到编导、素材、任务、校核和导出；这些为规格要求的必要工作面，不另添营销区、图表或假指标。

## 交付前检查

在浏览器实际操作编辑、保存、选片、排队和导出。最终用view_image对比主屏概念与最新浏览器截图；检查布局、文字层级、颜色、控件、时间轴、窄屏与上述必要偏差，并保留精简保真记录。
